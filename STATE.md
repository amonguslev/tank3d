## 1. Огляд проєкту
Тривимірна браузерна аркадна гра у стилі повномасштабного еволюційного римейку класичного **Battle City** із захистом штабу, руйнівними стінами, бонусами та новими геймплейними механіками, реалізована як **Progressive Web App (PWA)** з офлайн-режимом та підтримкою як ПК (клавіатура + миша), так і мобільних пристроїв (віртуальні стіки й тап-контроль).

### Технічний стек
- **Мова:** TypeScript (`strict: true`, ES2022)
- **3D-рушій:** `three` (`^0.170.0`) + `@types/three`
- **Збирач:** `vite` (`^6.0.0`)
- **PWA / Service Worker:** `vite-plugin-pwa` (`^0.21.1`, режим `generateSW`, автооновлення, Workbox precache)
- **Аудіо:** Процедурний синтезатор на базі `Web Audio API` (без зовнішніх аудіофайлів)
- **Збереження даних:** `localStorage` (ключ `tank_3d_pwa_save_v2`)

## 2. Особливості середовища та запуску
- **ОС:** Windows
- **Node.js / npm:** Встановлено у `C:\Program Files\nodejs\` (`node v26.13.1`, `npm 11.20.0`), але ця директорія не додана до глобального системного `PATH`.
- **Git:** Встановлено у `C:\Program Files\Git\cmd\git.exe` (викликається за повним шляхом, репозиторій ініціалізовано в корені проєкту з `.gitignore`).
- **Скрипти швидкого запуску** (автоматично додають `C:\Program Files\nodejs` у локальний `PATH`):
  - `start-dev.bat` — запуск Vite dev-сервера (`npm run dev -- --open`).
  - `start-pwa.bat` — повна продакшн-збірка та запуск локального PWA preview-сервера (`npm run build && npm run preview -- --open`).
- **Команди `package.json`:**
  - `npm run dev` — режим розробки
  - `npm run build` — перевірка типів `tsc` + продакшн-білд `vite build`
  - `npm run preview` — перегляд зібраної PWA-версії з `dist/`

## 4. Архітектура та фічі v2.0 (Узгоджений дизайн)

За результатами глибокої сесії `/grill-me`, римейк переходить на сучасний стандарт екшн-шутерів (Brawl Stars / Twin-Stick Shooter) із глибокою системою прогресії та новими режимамі гри:

### 1. 360° Twin-Stick керування
- **Вільний рух корпусу на 360°**: напрямок руху танка визначається клавішами WASD або лівим віртуальним стіком (незалежно від кута башти).
- **Незалежне обертання башти на 360°**: 
  - На ПК — прицілювання курсором миші (raycast на ігрову площину) + ЛКМ для стрільби.
  - На смартфоні — правий віртуальний стік (плавне перетягування для прицільного вогню 360° або короткий тап для швидкого автоприцілу у найближчого ворога).

### 2. Розширені арени `36×36` підблоків (`18×18` макроклітинок)
- Збільшений масштаб ігрового поля для складних тактичних маневрів.
- Плавне слідування камери за танком гравця.
- **Вибухові бочки**: об'єкти на арені, що детонують від влучань снарядів, завдаючи AoE-шкоди ворогам і оточенню.
- **Екранний радар**: тактичні стрілки-індикатори по краю екрана, що вказують напрямок на Штаб, поточного Боса та ворогів поза межами видимості камери.

### 3. HP-система та виживаність
- **Смужки здоров'я (HP)** над танком гравця та над Штабом.
- **Дроп ремкомплектів (`repair`)** для відновлення HP на полі бою.
- Збереження класичної системи **3 життів за забіг**.

### 4. 3D-Ангар, економіка монет та 4 класи танків
У v2.0 танки не мають окремої ульти — фокус зосереджений на унікальній основній зброї та стилі гри:
1. *Універсал «Козак»* — збалансована гармата (класичний надійний бієць).
2. *БТР «Стриж»* — висока швидкість, спарений скорострільний кулемет.
3. *РСЗВ «Град»* — стрільба ракетами з радіусом вибуху AoE (ураження груп цілей).
4. *Титан «Мамонт»* — важка броня, потужний пробивний рейлган (пробиває наскрізь ворогів та сталеві стіни).
- **Прокачка**: можливість покращувати 4 основні характеристики танка за зароблені в боях монети (швидкість руху, швидкість стрільби, шкода, броня/HP), а також міцність самого Штабу.

### 5. Два ігрові режими
1. **Кампанія (16 рівнів у 4 біомах)**:
   - Біом 1: *Промзона* (рівні 1–4)
   - Біом 2: *Пустеля* (рівні 5–8)
   - Біом 3: *Арктика* (рівні 9–12)
   - Біом 4: *Вулканічна фортеця* (рівні 13–16)
   - **Битви з Босами**: Кожен 4-й рівень завершується битвою з гігантським багатофазним Босом (включає червоні зони обстрілів та необхідність одночасної оборони Штабу).
2. **Нескінченна Орда**:
   - Нескінченні хвилі ворогів для фарму монет і встановлення рекордів.
   - Поява міні-босів кожні 5 хвиль.

### 6. Візуальний апгрейд (v2.0)
- Реалістичні сліди гусениць на землі.
- Кратери від потужних вибухів.
- Динамічні спалахи пострілів та світлові ефекти.
- Світіння та промінь рейлгана у «Мамонта».
- Спливаючі цифри шкоди (floating damage numbers).
