## 1. Огляд проєкту
«Танчики 3D: World of Tanks Edition» (v3.0) — це автентичний танковий екшн-шутер у стилі World of Tanks, створений як еволюція класичної концепції Battle City у повному 3D. Гра забезпечує тактичний геймплей на танкових шасі з реалістичною фізикою рельєфу, снайперським прицілом, 3D-ангаром, системою прокачки та двома захопливими режимами бою. Проєкт працює як **Progressive Web App (PWA)** з офлайн-режимом та підтримкою клавіатури, миші та мобільного сенсорного керування.

### Технічний стек
- **Мова:** TypeScript (`strict: true`, ES2022)
- **3D-рушій:** `three` (`^0.170.0`) + `@types/three`
- **Збирач:** `vite` (`^6.0.0`)
- **PWA / Service Worker:** `vite-plugin-pwa` (`^0.21.1`, режим `generateSW`, автооновлення, Workbox precache)
- **Аудіо:** Процедурний синтезатор на базі `Web Audio API` (без зовнішніх аудіофайлів)
- **Збереження даних:** `localStorage` (ключ `tank_3d_wot_save_v3`)

## 2. Особливості середовища та запуску
- **ОС:** Windows
- **Node.js / npm:** Встановлено у `C:\Program Files\nodejs\` (`node v26.13.1`, `npm 11.20.0`), але ця директорія не додана до глобального системного `PATH`.
- **Git:** Встановлено у `C:\Program Files\Git\cmd\git.exe` (викликається за повним шляхом, репозиторій ініціалізовано в корені проєкту з `.gitignore`).
- **Скрипти швидкого запуску** (автоматично додають `C:\Program Files\nodejs` у локальний `PATH`):
  - `start-dev.bat` — запуск Vite dev-сервера (`npm run dev -- --open`).
  - `start-pwa.bat` — повна продакшн-збірка та запуск локального PWA preview-сервера (`npm run build && npm run preview -- --open`).
  - `push-github.bat` — відправка гілки `main` на GitHub (`git push -u origin main` із автоматичним додаванням шляху до Git та інтерактивною авторизацією через Git Credential Manager).
- **Команди `package.json`:**
  - `npm run dev` — режим розробки
  - `npm run build` — перевірка типів `tsc` + продакшн-білд `vite build`
  - `npm run preview` — перегляд зібраної PWA-версії з `dist/`

### Деплой на GitHub Pages (CI/CD)
- Налаштовано GitHub Actions workflow (`.github/workflows/deploy.yml`) для автоматичної збірки та публікації PWA на GitHub Pages при пуші в гілки `main` або `master` (а також вручну через `workflow_dispatch`).
- Автоматичне визначення `BASE_PATH`: workflow формує шлях для `npm run build` (`/${{ github.event.repository.name }}/` або `/` для `<user>.github.io`).
- `vite.config.ts` використовує змінну оточення `BASE_PATH`, передаючи її як базовий префікс у конфіг Vite та у `start_url` / `scope` PWA Web App Manifest, забезпечуючи повноцінну роботу PWA та кнопку встановлення як локально, так і в піддиректорії GitHub Pages.

## 4. Архітектура та фічі v3.0–v3.6 (World of Tanks Edition)

- **Справжня 3D-камера World of Tanks**: вид іззаду за баштою з вільним оглядом мишкою/свайпом. Снайперський режим (`Shift` або ПКМ) із зумом `x2`/`x4`, далекоміром та динамічним колом зведення ствола.
- **Танкове шасі на 3D-рельєфі**: пагорби, схили, скелі, бункери, кущі та вибухові бочки на 4 картах («Малинівські Пагорби», «Піщаний Каньйон», «Полярний Рубіж» та нова «Вулканічна Долина» з розломами лави та базальтом).
- **Супутниковий арт-приціл (Орбітальний режим на 100% карти)**: при перемиканні на слот `[2] Арта` та увімкненні снайперського прицілу камера злітає вертикально на орбіту (165–240м), показуючи всю арену 190×190 метрів від краю до краю з орієнтацією на північ.
- **Чесний барабан артилерії на 2 постріли за 10 секунд**: швидкий інтервал між пострілами 0.5с, 10 секунд перезарядки барабана після 2-го пострілу, авто-дозарядка через 10с при 1 невикористаному снаряді.
- **Вогонь по всій карті**: знято будь-які обмеження на дальність — стріляй у будь-яку точку карти мишкою або прямим тапом/кліком по екрану.
- **3D-Ангар**: карусель із 5 рівнів танків (`I`–`V` lvl), прокачка 4 модулів за срібло, система **🎨 Камуфляжів і Тюнінгу** (8 скінів: Стандарт, Лісовий, Пустеля, Зимовий, Червоний, Черв.-чорний, VIP Золото, Неон Кібер з миттєвим 3D-прев'ю та збереженням для кожного танка), чесна прогресія відкриття танків за зароблені в боях монети.
- **Флагманський танк V рівня «Т-5 Електро-Левіафан»**: подовжений корпус і дві незалежні поворотні башти з перемиканням камери та вогню між слотом `[1]` (152-мм електро-гармата Тесла з ланцюговими 3D-блискавками) та слотом `[2]` (задня скорострільна міні-арта «Джміль» на кормі).
- **Аркадна динамічна HP-система**: без рикошетів, тактичний ремкомплект `[3 / R]`, дроп підсилень, квадратна мінікарта WoT та 2D-маркери ворогів.
- **Три режими бою**: **«Нескінченні хвилі»** (із Босами кожні 5 хвиль), **«Битва 1 на 1»** (дуель із Чемпіоном) та **«Командний бій 5 на 5 + Захоплення бази»** (4 союзні боти проти 5 ворогів, центральне коло бази з прапором, сирена, ростер `5 : 5` і маркери на мінікарті).
